# MNIST Handwritten Digit Classification

A machine learning project that uses the MNIST dataset to classify handwritten digits from 0 to 9 using Python and deep learning.

## Project Overview

Handwritten digit classification is a computer vision task that involves teaching a machine learning model to identify numerical digits from images.

This project explores image preprocessing, model training, and evaluation to understand how machine learning can be applied to image recognition.

## Objectives

- Explore and visualise handwritten digit images.
- Prepare image data for model training.
- Develop a model to classify digits from 0 to 9.
- Evaluate the model using test data.
- Visualise model predictions and misclassified examples.

## Dataset

The project uses the MNIST handwritten digit dataset.

- **Image dimensions:** 28 × 28 pixels
- **Image type:** Grayscale
- **Number of classes:** 10 (digits 0–9)

The standard MNIST dataset contains 60,000 training images and 10,000 test images. The actual dataset split used in this project should be confirmed from the notebook.
